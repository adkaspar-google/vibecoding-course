# Document Typography & Structure Reference (`docs.md`)

Loaded on demand from `SKILL.md` only when authoring or styling written documents, RFCs, or study guides.

## 1. Page Geometry & Margins
- Page margins: `64pt` top/bottom, `64pt` left/right.
- Line height: `1.45` for body copy; `1.20` for headings.
- Paragraph rhythm: One core concept per paragraph (`10pt` vertical separation).

## 2. Typographic Scale
- `H1`: `24pt` `Styrene A` Bold in `#141413` (`brand-charcoal`).
- `H2`: `18pt` `Styrene A` SemiBold in `#141413` with `2pt` `#D97757` bottom accent rule.
- `Body`: `11pt` `Tiempos Text` Regular in `#141413` on `#FAF9F5`.
- `Code`: `9.5pt` `JetBrains Mono` on `#F0EFEA` container fill.
