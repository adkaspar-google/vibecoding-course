# Presentation Slide Deck Reference (`slides-deck.md`)

Loaded on demand from `SKILL.md` only when creating or reviewing `16:9` widescreen presentation slides.

## 1. Widescreen `16:9` Canvas Grid
- Aspect ratio: `16:9` (`1920x1080` px or `16cm x 9cm` Beamer canvas).
- Background surface: `#FAF9F5` (`brand-ivory`) for content slides; `#141413` (`brand-charcoal`) with `#FAF9F5` text for section divider slides.
- Safe margin: `36pt` minimum clearance from all slide edges.

## 2. Visual Density Guardrails
- Maximum `3` data cards or columns per slide.
- Minimum font size on slides: `14pt` for body bullets, `10pt` for diagram node labels.
- Accent callout bars use `#D97757` (`brand-terracotta`) on the left border (`4pt` width).
