\slideshell{02 / 36}{MODULE 01: PHILOSOPHY OF CODE}{Unmesh Joshi's ``What Is Code?'' (May 2026): Code as a Model of Understanding}{Why cheaper LLM syntax makes domain vocabulary, explicit conceptual models, and active thinking more important than ever}{
  \bcard{0}{0}{7.1}{3.95}{gbgred}{gred}{
    {\fontsize{15.5}{19}\selectfont\bfseries\textcolor{gred}{The Trap: ``Ralph Wiggum'' Vibe Coding \& Cognitive Debt}}\\[7pt]
    \textbf{1. Passive Diff Review:} Treating the LLM as a black-box syntax generator and judging output only by whether a demo runs.\\[4pt]
    \textbf{2. Vocabulary \& Synonym Drift:} Across three prompts, the agent invents \code{client\_id}, \code{cust\_acct}, and \code{user\_id} for the same account entity.\\[4pt]
    \textbf{3. IEEE-754 Float Corruption:} Mixing \code{tx\_amt = 19.99} floats instead of integer minor units (\code{MoneyCents}), breaking conservation.\\[4pt]
    \textbf{4. Silent Hallucination:} Guessing missing exchange rates (\code{rate = 1.0}) instead of asking a coworker-style clarifying question.
  }
  \bcard{7.6}{0}{7.1}{3.95}{gbggreen}{ggreen}{
    {\fontsize{15.5}{19}\selectfont\bfseries\textcolor{ggreen}{The Solution: Explicit Conceptual Models \& Vocabulary}}\\[7pt]
    \textbf{1. Unmesh Joshi's Thesis (martinfowler.com):} ``We are not meant to be passive reviewers of generated code. The act of writing code is itself part of our thinking.''\\[4pt]
    \textbf{2. Ubiquitous Language Value Objects:} Encode domain nouns and invariants directly into frozen types (\code{AccountId}, \code{MoneyCents}, \code{SettlementBatch}).\\[4pt]
    \textbf{3. Iterative Vocabulary Refinement:} Refine domain terms through feedback, domain expertise, and deterministic tests.\\[4pt]
    \textbf{4. Foundation for Humans + LLMs:} Clean abstractions compress context so both humans and agents reason accurately.
  }

  \bcard{0}{-4.20}{14.7}{2.10}{gbgblue}{gblue}{
    {\fontsize{14.5}{18}\selectfont\bfseries\textcolor{gblue}{Core Principle: Code Is Still Instructions for a Machine---But Primarily a Model of Understanding}}\\[5pt]
    $\bullet$ ``As LLMs make code generation cheaper, the mechanical act of writing instructions becomes less central. What becomes more important is \textbf{making the conceptual model explicit, discovering the right vocabulary, and refining that vocabulary through iteration, domain expertise, and feedback}.'' --- \emph{Unmesh Joshi, martinfowler.com, May 2026}
  }

    \textbf{\emph{Philosophical Investigations} (1953):}\\[3pt]
    $\bullet$ Words are tools in a collaborative \textbf{Language Game} (\emph{Builder \& Assistant}, \code{§2}, \code{§43}).\\[3pt]
    $\bullet$ \textbf{Vibe Coding Analog:} Using natural language with an AI coworker inside a shared context (\code{CLAUDE.md}/\code{GEMINI.md}, Skills) to coordinate actions and produce code (\code{arXiv:2302.01570}).

    $\bullet$ 100 players instructing an AI builder via language: success depends on \textbf{avoiding synonyms} \& \textbf{reusable abstractions} (Skills).\\[3pt]

\slideshell{07 / 36}{MODULE 02: LAB 01 STEP-BY-STEP (1 / 5)}{Lab 01 Problem: The ``Vibe-Coded'' Payments Ledger Disaster}{Inspecting \texttt{labs/lab\_01\_vocabulary\_and\_bounded\_language\_games/starter/domain\_ledger.py}}{
  \bcard{0}{0}{7.1}{4.1}{gbgred}{gred}{
    {\fontsize{15.5}{19}\selectfont\bfseries\textcolor{gred}{What the Ungrounded ``Vibe-Coded'' Starter Does Wrong}}\\[7pt]
    \textbf{1. Synonym Soup (\code{starter/domain\_ledger.py}):}\\[3pt]
    $\bullet$ Accepts arbitrary dict keys (\code{acct}, \code{client\_id}, \code{cust\_acct}, \code{user\_id}) with zero regex or type validation.\\[4pt]
    \textbf{2. IEEE-754 Float Drift:}\\[3pt]
    $\bullet$ Uses \code{float(entry.get("tx\_amt", 0.0))}, accumulating \code{0.1 + 0.2 != 0.3} penny errors across settlement batches.\\[4pt]
    \textbf{3. Silent FX Hallucination:}\\[3pt]
    $\bullet$ When asked to settle \code{JPY -> USD} without a grounded FX rate, it silently invents \code{rate = 1.0} and executes!
  }
  \bcard{7.6}{0}{7.1}{4.1}{gbggreen}{ggreen}{
    {\fontsize{15.5}{19}\selectfont\bfseries\textcolor{ggreen}{Target Architecture: Shared Vocabulary \& Clarification Gate}}\\[7pt]
    \textbf{1. Ubiquitous Language Value Objects (\code{REQ-0101..0102}):}\\[3pt]
    $\bullet$ Frozen \code{AccountId} (\code{\textasciicircum{}ACCT-[A-Z0-9]\{4,12\}\$}) and \code{MoneyCents(amount\_cents: int, currency: str)}.\\[4pt]

\slideshell{25 / 36}{MODULE 05: LAB 04 STEP-BY-STEP (4 / 5)}{Lab 04 Step 3 (\texttt{REQ-0405}): Signal Detection Theory ($d'$, Criterion Bias $c$, Utility $U$)}{Calibrating skill trigger descriptions mathematically with Hautus (1995) $+0.5$ smoothing}{
  \bcard{0}{0}{7.1}{4.15}{gbgblue}{gblue}{
    {\fontsize{15.0}{18.5}\selectfont\bfseries\textcolor{gblue}{Hautus (1995) Smoothed SDT Equations (\texttt{compute\_sdt\_metrics})}}\\[6pt]
    $\bullet$ Given Hits ($H$), Misses ($M$), False Alarms ($FA$), and Correct Rejections ($CR$) on a 60/40 train/test split:\\[4pt]
    $$\text{HR}_{\text{adj}} = \frac{H + 0.5}{H + M + 1.0}, \qquad \text{FA}_{\text{adj}} = \frac{FA + 0.5}{FA + CR + 1.0}$$\\[2pt]
    $$d' = \Phi^{-1}(\text{HR}_{\text{adj}}) - \Phi^{-1}(\text{FA}_{\text{adj}}), \qquad c = -\frac{1}{2}\left[\Phi^{-1}(\text{HR}_{\text{adj}}) + \Phi^{-1}(\text{FA}_{\text{adj}})\right]$$\\[2pt]
    $$U = 2.0 \cdot d' - 0.5 \cdot |c - c_{\text{target}}|$$
  }
  \bcard{7.6}{0}{7.1}{4.15}{gbggreen}{ggreen}{
    {\fontsize{15.0}{18.5}\selectfont\bfseries\textcolor{ggreen}{Interpreting $d'$ and Criterion Bias $c$}}\\[6pt]
    $\bullet$ \textbf{Sensitivity $d'$ (Discriminability):}\\[3pt]
    -- $d' > 2.0$: Strong separation between positive and distractor prompts.\\[2pt]
    -- $d' \le 0$: Trigger is no better than random coin tossing.\\[5pt]
    $\bullet$ \textbf{Criterion Bias $c$ (Threshold Placement):}\\[3pt]
    -- $c > +0.25$: \code{"conservative"} (under-triggering / misses).\\[2pt]
    -- $c < -0.25$: \code{"liberal"} (over-triggering / false alarms).\\[2pt]
    -- $|c| \le 0.25$: \code{"balanced"} (optimal operating point).
  }
