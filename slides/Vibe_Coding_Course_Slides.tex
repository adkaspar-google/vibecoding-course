\slideshell{02 / 36}{MODULE 01: LANGUAGE, CODE \& SE FUNDAMENTALS}{Why Language Produces Code \& Actions: Fowler, Wittgenstein \& Ng}{Unmesh Joshi \& Martin Fowler (\emph{What Is Code?}), Wittgenstein's Two Theories of Language, and Andrew Ng's SE Steering Rule}{
  \bcard{0}{0}{4.7}{4.05}{gbgblue}{gblue}{
    {\fontsize{14.5}{18}\selectfont\bfseries\textcolor{gblue}{1. Unmesh Joshi \& Martin Fowler}}\\[5pt]
    \textbf{\emph{What Is Code?} (\code{martinfowler.com}):}\\[3pt]
    $\bullet$ Code is not merely syntax for a machine; it is an explicit \textbf{externalized conceptual model}.\\[3pt]
    $\bullet$ Passive ``vibe reviewing'' creates massive \textbf{Cognitive Debt} (synonym drift, untyped dicts, silent assumptions).\\[3pt]
    $\bullet$ As syntax becomes cheap, \textbf{discovering precise domain vocabulary} and invariants becomes the core engineering bottleneck.
  }
  \bcard{5.0}{0}{4.7}{4.05}{gbgsteel}{gsteel}{
    {\fontsize{14.5}{18}\selectfont\bfseries\textcolor{gsteel}{2. Wittgenstein's Two Theories}}\\[5pt]
    \textbf{Why Natural Language Coordinates Code:}\\[3pt]
    $\bullet$ \textbf{Early \emph{Tractatus} (Picture Theory):} Formal 1-to-1 logical structure---analogous to compilers, static types, and deterministic unit tests.\\[3pt]
    $\bullet$ \textbf{Late \emph{Investigations} (Language-as-Action):} Words are active tools in a shared workspace (\code{arXiv:1606.02447}, \code{arXiv:2302.01570}).\\[3pt]
    $\bullet$ Collaborative prompting aligns intent so the agent emits formal, test-verified code.
  }
  \bcard{10.0}{0}{4.7}{4.05}{gbgindigo}{gnavy}{
    {\fontsize{14.5}{18}\selectfont\bfseries\textcolor{gdark}{3. Andrew Ng's SE Steering Rule}}\\[5pt]
    \textbf{Why Fundamentals Beat Raw Vibes:}\\[3pt]
    $\bullet$ A novice who vibe codes without \textbf{Software Engineering Fundamentals} lets the agent make poor default tradeoffs.\\[3pt]
    $\bullet$ Without explicit constraints, agents ignore \textbf{latency, consistency, idempotency, reliability, maintainability, and blast radius}.\\[3pt]
    $\bullet$ Precise architectural vocabulary is the steering wheel of an AI coding agent.
  }

  \bcard{0}{-4.25}{14.7}{2.05}{gbggray}{gnavy}{
    {\fontsize{14}{17.5}\selectfont\bfseries\textcolor{gnavy}{The Conceptual Synthesis: Conversational Alignment $\to$ Architectural Constraints $\to$ Deterministic Verification}}\\[4pt]
    $\bullet$ \textbf{Naive Vibe Prompt:} \code{"Build a webhook payment handler"} $\to$ Produces non-idempotent float math, unbounded retries, and SQL injection vectors.\\[2pt]
    $\bullet$ \textbf{SE-Steered Prompt:} \code{"Implement an idempotent webhook handler using integer minor units, p99 < 50ms bounded retries, and strict schema validation."}
  }
